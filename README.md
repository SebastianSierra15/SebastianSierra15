## Sobre mí

Soy estudiante de Ingeniería de Sistemas y desarrollador full stack. Me interesa convertir necesidades reales en productos web claros, funcionales y preparados para crecer.

Me muevo entre frontend, backend, bases de datos y despliegue: desde una interfaz React/Next.js hasta una API con autenticación, un modelo de datos, un dashboard o un servicio Dockerizado en producción.

## En qué trabajo

- Productos web y plataformas con React, Next.js, TypeScript y Vite.
- APIs REST y sistemas backend con Java, Spring Boot, Spring Security y Node.js.
- Dashboards, paneles administrativos y flujos orientados a datos.
- Autenticación, validación, persistencia, documentación OpenAPI y despliegues reproducibles.
- Automatización y desarrollo asistido por IA para explorar, documentar y entregar mejor software.

## Cómo trabajo

- Empiezo por entender el problema, el flujo de usuario y la regla de negocio.
- Prefiero componentes reutilizables, APIs claras y modelos de datos explícitos.
- Me siento cómodo conectando interfaz, backend, base de datos, despliegue y diagnóstico.
- Documento las decisiones importantes para que el proyecto pueda evolucionar después del primer release.
